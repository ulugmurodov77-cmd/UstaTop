
# UstaTop

O'zbekiston uchun zamonaviy xizmatlar marketplace platformasi.

## Texnologiyalar
- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage
- Lucide Icons

## Ishga tushirish
1. UstaTop papkasini VS Code'da oching.
2. index.html faylini oching.
3. Live Server orqali ishga tushiring.

## Mavjud funksiyalar
- Xizmatlarni qidirish
- Kategoriyalar bo'yicha filtrlash
- Narx va reyting bo'yicha saralash
- Sevimlilar
- Buyurtma berish
- Demo profil yaratish
- Mutaxassislikka ariza yuborish
- Dark / Light mode
- Responsive dizayn

## Muhim
Bu frontend demo versiyasi. Haqiqiy SMS tasdiqlash,
server orqali buyurtma yuborish, to'lovlar va admin
boshqaruvi uchun backend va ma'lumotlar bazasi kerak.
